# Folder Asset 3D (.GLB) Polaris

Folder ini adalah tempat meletakkan file 3D berformat `.glb` (hasil generate dari **Tripo 3D** atau download dari **Sketchfab**):

1. `act1-phone.glb`   -> Model 3D Smartphone / Jam Subuh 02:14 AM (Babak 1)
2. `act2-skillet.glb` -> Model 3D Wajan Pan / Pasta Aglio Olio (Babak 2)
3. `act3-sculpture.glb` -> Model 3D Patung Siluet / Resonansi Batin (Babak 3)
4. `act4-moscow.glb`  -> Model 3D Kubah Katedral Moscow / Bus Malam (Babak 4)
5. `act5-polaris.glb` -> Model 3D Bintang Polaris Emas / Kompas Abadi (Babak 5)

Setiap file `.glb` yang ditaruh di sini akan otomatis dimuat dan dianimasikan secara interaktif (3D orbit & lighting) oleh komponen `ModelViewerGLB.tsx`.
